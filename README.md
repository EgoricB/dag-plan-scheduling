# DAG-Plan: учебная реализация и оптимизация расписания

Весь проект в одном архиве: исходники, два примера DAG, конспект, сопоставление со статьёй, отчёт, 14 тестов и результаты 100 сценариев.
Это учебная реконструкция диспетчера, НЕ официальный код и НЕ полная робототехническая система авторов.

## Запуск
Распакуйте архив и откройте терминал в этой папке. Нужен Python 3.10+; сторонние библиотеки не нужны.

```bash
python dag_plan.py examples/parallel.json
python dag_plan.py examples/holding.json
python -m unittest -v test_dag_plan.py
python benchmark.py
```

Сохранить журнал для будущего лендинга:
```bash
python dag_plan.py examples/parallel.json --output results/parallel.json
```

## Два режима
baseline: предпочтение максимально параллельного допустимого назначения, затем минимум суммы расстояний.
optimized: точный поиск расписания по полному времени исполнения с мемоизацией, до 8 физических действий.
Ограничения и временная модель одинаковы. Точный поиск считается дольше, но улучшает расписание. Токенная экономия не заявляется: LLM отсутствует в обоих вариантах.

Демонстрация: 20 → 13 условных секунд. В 100 графах по 6 действий — 58 улучшений, 42 равенства, среднее относительное снижение 4,48%. Это синтетические данные, не авторский роботический benchmark.
