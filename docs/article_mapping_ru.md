# Соответствие исходной статье

Источник: https://arxiv.org/html/2406.09953v3 .

## Сохранено из алгоритмического ядра
- DAG зависимостей и число рук на узел.
- occupy/tool/release/operate/complete.
- Доступность узла после выполнения предшественников.
- Для занятой руки — продолжение собственной цепочки удержания.
- Проверки будущей занятости, расстояния между целями и расположения/достижимости.
- Авторский J: сумма расстояний обеих рук до соответствующих целей.
- Обновление состояния после исполнения; LLM не нужна для каждого выбора.

## Явные учебные допущения
1. Граф задаётся JSON вместо генерации и исправления LLM.
2. Координаты двумерные; рабочие зоны — диски вокруг фиксированных баз рук, пересечение рук приближённо исключается порядком целей по X. Это не проверка траекторий и столкновений.
3. Цепочки удержания линейны, число рук неизменно; до захвата завершены все внешние зависимости всей цепочки. Это консервативная интерпретация, не точный опубликованный псевдокод авторов.
4. Приоритет максимальной занятости рук до минимума J — наше разрешение неоднозначности ожидания; в статье нет отдельного слагаемого простоя.
5. При равенстве J — порядок идентификаторов.
6. Каждый узел ведёт к единственному Complete; это усиленная структурная валидация.
7. Навыки успешны, исполнение символическое, следующая стадия начинается после окончания обеих операций.

## Что добавлено
- Длительности, скорость и общая временная модель оценки.
- Точный оптимизатор полного расписания с мемоизацией.
- Автоматические тесты и воспроизводимый генератор 100 малых графов.

Ресурсные блокировки предыдущего прототипа убраны. Оба режима используют один feasible_pairs. Оптимизатор вправе предпочитать ожидание: это часть изменения политики выбора, не скрытое изменение физической допустимости.
Нельзя писать «точная реплика авторского исходника» или «воспроизведены авторские 74% успешности». Корректно: «учебная реконструкция диспетчера DAG-Plan с явно обозначенными допущениями».
